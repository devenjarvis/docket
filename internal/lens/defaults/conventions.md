Read `rules.json` and the repository's own stated conventions: CONTRIBUTING, docs, linter and formatter configuration, and the patterns the surrounding code already follows. Find where this change breaks one. Leftover debugging (print statements, commented-out code, a TODO with no owner), dead code, and code duplicated from somewhere it could have been reused count too.

Name the rule's id, or the file that states the convention, for each finding. Style a formatter would fix is not a finding.
